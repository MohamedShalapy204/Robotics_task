# 🔋 Power Supply Team (Team 4)

## 🎯 Objectives
- Monitor electrical load and voltage drops.
- Implement Emergency Stop (E-Stop) safety logic.
- Ensure stable 5V/12V distribution to servos and controller.

## 📁 Required Deliverables
1. `safety_monitor.py`: A script to check system health and current draw.
2. `specs.json`: Configuration for maximum torque and power limits.

## 🛠 Integration Contact
The Power team provides safety interlocks for the **Embedded Team** and ensures the **Structure Team's** motors have enough current.
