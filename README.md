## 🏗 Project Architecture

The project is divided into 5 specialized subsystem folders in `src/`:

1. `vision/` - Object detection & Camera calibration.
2. `kinematics/` - Simulation & Inverse Kinematics.
3. `embedded/` - Arduino firmware & Serial communication.
4. `power/` - Safety monitoring & Power specs.
5. `structure/` - 3D models & physical dimensions.

For more details on team responsibilities, check the [Source README](src/README.md).
