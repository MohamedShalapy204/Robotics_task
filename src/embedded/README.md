# ⚡ Embedded Team (Team 3)

## 🎯 Objectives
- Arduino C++ firmware development.
- Serial communication protocol (receiving angles and moving servos).
- Implementation of safe movement limits in the firmware.

## 📁 Required Deliverables
1. `firmware.ino`: The code that runs on the Arduino.
2. `bridge.py`: A Python serial handler to send commands like `M J1 J2 J3 J4`.

## 🛠 Integration Contact
The Embedded team receives `angles` from the **Kinematics Team** and controls the physical **Power/Motor** hardware.
