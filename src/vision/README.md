# 📷 Vision Team (Team 1)

## 🎯 Objectives

- Real-time object detection using OpenCV.
- Color segmentation (filtering Red, Green, Blue objects).
- Coordinate transformation from Camera Pixels to Workspace CM.

## 📁 Required Deliverables

1. `detector.py`: A class that captures frames and returns a list of detected objects (Color, X, Y).
2. `calibration.py`: A script to map camera distortion and physical scale.

## 🛠 Integration Contact

The Vision team outputs an `(x, y)` target which is consumed by the **Kinematics Team**.
